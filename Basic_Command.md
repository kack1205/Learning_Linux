# Basic commands

[!NOTE]

* `` pwd `` - Know the current directory where you are.

  /home/debian


* `` ls `` - Show files and folders available in current folder path.

  Desktop  Documents  Downloads  Music  Pictures  Public  Templates  Videos


* `` ls -l `` - Show files and folders with details.

  total 32  
  drwxr-xr-x 2 debian debian 4096 May  3 15:43 Desktop  
  drwxr-xr-x 2 debian debian 4096 May  3 15:43 Documents  
  drwxr-xr-x 2 debian debian 4096 May  3 15:43 Downloads  
  drwxr-xr-x 2 debian debian 4096 May  3 15:43 Music  
  drwxr-xr-x 2 debian debian 4096 May  3 15:43 Pictures  
  drwxr-xr-x 2 debian debian 4096 May  3 15:43 Public  
  drwxr-xr-x 2 debian debian 4096 May  3 15:43 Templates  

* `` ls -a `` - Show files and folders with hidden files and folders
> [!NOTE]
> Hidden files and folders are started with '.' in linux

> [!NOTE]
> **Quick Tip:** Use backticks `` `text` `` for a gray inline highlight like `this`.
